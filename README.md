# 🚀 SocialX – Scalable Social Media Backend (ASP.NET Core)

SocialX is a scalable and production-ready social media backend built using ASP.NET Core, following Clean Architecture & Onion Architecture principles.

The project simulates core features of platforms like Twitter, including tweets, comments, likes, follows, bookmarks, mentions, hashtags, and real-time notifications.

---

# 🏗 Architecture & Design

- Clean Architecture (Domain / Application / Infrastructure / API)
- Repository Pattern & Unit of Work
- SOLID Principles
- Dependency Injection
- Global Exception Handling Middleware
- DTOs + AutoMapper
- Soft Delete implementation
- Pagination support

---

# 🔐 Authentication & Authorization

- ASP.NET Identity
- JWT Authentication
- Role-Based Authorization (Admin / User)
- Refresh Tokens
- Custom Claims handling

---

# 🧠 Core Features

- Create / Update / Delete Tweets
- Nested Comments & Replies
- Like / Unlike (Tweets & Comments)
- Follow / Unfollow Users
- Mentions & Hashtags
- Bookmarks
- User Profiles
- Feed with Pagination
- Edit Comment support

---

# 🔔 Real-Time Notifications (SignalR)

- Real-time notifications when:
  - Someone likes your tweet
  - Someone likes your comment
  - Someone follows you
- SignalR Hub with User-based Groups
- JWT-secured WebSocket connection
